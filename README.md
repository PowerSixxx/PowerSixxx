## Projects

### 🛒 Distributed Online Shopping Platform
**Tech Stack:** `Spring Cloud` • `AWS ECS / ECR / SQS / DynamoDB` • `Redis & Lua` • `Docker` • `AWS CDK`.
- Designed a high-concurrency microservices architecture supporting peak flash-sale scenarios (up to 10K QPS).
- Implemented inventory caching with **Redis + Lua scripts** using the **TCC (Try-Confirm-Cancel)** pattern to guarantee zero overselling.
- Handled burst traffic via **AWS SQS** async queue pipelines and automated deployments using **AWS CDK / CloudFormation** and **CodePipeline**.

### 🤖 Enterprise RAG Knowledge Retrieval Platform
**Tech Stack:** `LangChain` • `FastAPI` • `pgvector` • `Cohere Embeddings` • `FAISS` • `BM25`.
- Built an enterprise-grade document ingestion and retrieval pipeline supporting 100+ concurrent queries.
- Implemented hybrid search combining **vector similarity search** with **BM25 keyword retrieval** for high-precision domain-specific retrieval.

### 👥 Full-Stack User Center System
**Tech Stack:** `React` • `Ant Design Pro` • `Spring Boot` • `MyBatis-Plus` • `MySQL` • `Docker`.
- Production-ready authentication, role-based access control, and user management platform.
- Implemented robust RESTful APIs, database schema modeling, and modern responsive front-end pages.
